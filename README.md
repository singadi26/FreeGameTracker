# Free Game Tracker

## Project Goal
Free Game Tracker is a Java application designed to help users discover limited-time free video game giveaways from platforms such as Steam and Epic Games Store. The goal is to make it easier to find and claim free games before their offers expire.

## Minimum Viable Product (MVP)
The first version of the application will focus on three core features:

1. Retrieve current free game giveaways from an external data source.
2. Display game titles, platforms, and offer expiration dates.
3. Provide links for users to claim available free games.

## Tech Stack
- Programming Language: Java
- Development Environment: IntelliJ IDEA
- Libraries: Java HttpClient, Gson, and Java date/time utilities (proposed)
- Data Storage: JSON or text files if needed
- External Data Source: GamerPower API (tentative, pending testing)
- Version Control: Git and GitHub

## Future Plans
Features that may be added in later versions include:

- Notifications when new free games become available.
- The ability to mark games as claimed.
- A history of previously available free game giveaways.
